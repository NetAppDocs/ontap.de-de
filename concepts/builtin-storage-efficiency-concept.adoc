= Informationen zur Speichereffizienz des dedizierten ONTAP Offload-Prozessors
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Die Speichereffizienz durch dedizierte Offload-Prozessoren führt die sequenzielle Packung angrenzender physischer Blöcke durch und nutzt einen dedizierten Offload-Prozessor für 32k Datenkomprimierung. Mit 32k Komprimierung wird Speicherplatz auf Aggregatebene eingespart, im Gegensatz zu Systemen mit adaptiver 8k Komprimierung, bei denen die Speicherplatzeinsparung auf Volumenebene erfolgt. Systeme, die dedizierte Offload-Prozessor-Speichereffizienz verwenden, nutzen keine temperaturabhängige Speichereffizienz (TSSE), das bedeutet, die Komprimierung basiert nicht auf heißen oder kalten Daten. Dadurch ergeben sich sofortige Speicherplatzeinsparungen ohne Leistungseinbußen.

Die dedizierte Offload-Prozessor-Speichereffizienz wird auf den folgenden Systemen unterstützt. Sie ist auf den aufgeführten AFF Systemen standardmäßig aktiviert.


NOTE: AFF A20 Plattform unterstützt keine dedizierte Offload-Prozessor-Speichereffizienz. Bei AFF A20 Systemen werden mit SnapMirror Technologie migrierte Daten automatisch mithilfe der Haupt-CPU in 32k Inline-Komprimierung konvertiert.

* AFF A-Series Systeme: AFF A90, AFF A70, AFF A50, AFF A30
* AFF A1K
* AFF C-Series Systeme: AFF C80, AFF C60, AFF C30
* FAS Systeme: FAS90, FAS70, FAS50


Bei den folgenden Systemen ist die Speichereffizienz automatisch aktiviert und erfordert keine Konfiguration. Dies gilt für alle neu erstellten Thin-Provisioned-Volumes und vorhandene Daten, einschließlich Volumes, die von anderen Systemen verschoben wurden. Die Deduplizierung ist unabhängig von der Speicherplatzzusage aktiviert. Komprimierung und Datenverdichtung setzen voraus, dass die Speicherplatzzusage auf Keine gesetzt ist. Daten, die mithilfe von Volume Move oder der SnapMirror Technologie migriert werden, werden automatisch in 32k Inline-Komprimierung konvertiert.

* AFF A-Series Systeme: AFF A90, AFF A70, AFF A50, AFF A30
* AFF A1K
* AFF C-Series Systeme: AFF C80, AFF C60, AFF C30


Bei den folgenden Systemen ist die Speichereffizienz standardmäßig nur auf bestehenden Thin-Provisioned-Volumes aktiviert, auf denen die Speichereffizienz bereits vor dem Upgrade auf ONTAP 9.15.1 oder später aktiviert war. Die Speichereffizienz kann für neu erstellte Volumes mithilfe der ONTAP CLI oder der ONTAP REST API Methode aktiviert werden. Daten, die mithilfe von Volume Move oder SnapMirror Technologie migriert werden, werden nur dann in 32k Inline-Komprimierung konvertiert, wenn die Komprimierung auf der ursprünglichen Plattform aktiviert war.

* FAS90
* FAS70
* FAS50


Informationen zum Upgrade eines Controllers auf eines der unterstützten Systeme sind unter  https://docs.netapp.com/us-en/ontap-systems-upgrade/choose_controller_upgrade_procedure.html["ONTAP Hardware Upgrade Dokumentation"^] zu finden.
