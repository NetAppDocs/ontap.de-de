= Anzeigen von Clusterinformationen im ONTAP System Manager Dashboard
:hardbreaks:
:toclevels: 1
:allow-uri-read: 
:toclevels: 1
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Das System Manager Dashboard bietet eine schnelle und umfassende Übersicht über Ihren ONTAP Cluster an einem zentralen Ort.

Im System Manager Dashboard können Informationen zum Systemstatus Ihres Clusters, zu Kapazität, Netzwerk und Performance angezeigt werden, darunter wichtige Warnmeldungen, die Effizienz und Kapazität von Storage Tiers und Volumes, der Status und die Verfügbarkeit von Clusterknoten, die aktivsten Anwendungen und Objekte sowie Performance-Metriken.

Ab ONTAP 9.19.1 können SVM-Administratoren ihre eigenen SVMs über ein spezielles SVM-Administrator-Dashboard im ONTAP System Manager überwachen und verwalten. Weitere Informationen finden sich unter link:task-svm-admin-dashboard-sm.html["Verwalten und überwachen Sie SVMs mit System Manager"].

Das Dashboard umfasst vier Bereiche, die wie folgt beschrieben sind:



[[view-the-cluster-health]]
== Anzeigen des Cluster-Systemstatus

Im Abschnitt *Systemstatus* des ONTAP System Manager Dashboard können Sie allgemeine Informationen zu Ihrem Cluster anzeigen, z. B. seinen Namen, die ONTAP Version und das Erstellungsdatum. Außerdem können Sie den allgemeinen Systemstatus Ihrer Clusterknoten sowie Fehler, Warnungen, Alarme auf Clusterebene und vorgeschlagene Änderungen zur Verbesserung der Cluster Performance anzeigen.

Ab ONTAP 9.20.1 wird 30 Tage vor Ablauf eines Zertifikats für einen Cluster oder eine Storage Virtual Machine (SVM) eine Systemstatuswarnung angezeigt. Die Warnung wird täglich aktualisiert und zeigt die Anzahl der bis zum Ablauf verbleibenden Tage an. Sie können den standardmäßigen Warnschwellenwert von 30 Tagen auf eine beliebige Anzahl von Tagen von 0 bis 90 ändern, ihn deaktivieren, sodass keine Warnungen angezeigt werden, oder Warnungen für bereits abgelaufene Zertifikate unterdrücken und gleichzeitig weiterhin Warnungen für bevorstehende Abläufe erhalten.

* Zum Anzeigen von Informationen zum Cluster-Systemstatus ist auf dem Dashboard neben *Systemstatus* image:icon_arrow.gif["Pfeilsymbol"] auszuwählen.
* Zum Ändern der Einstellung für den Zertifikatsablauf wird die Warnung und anschließend *Certificate Settings* ausgewählt.




[[view-the-cluster-capacity]]
== Clusterkapazität anzeigen

Im Abschnitt *Kapazität* des ONTAP System Manager Dashboard können Sie den Storage-Speicherplatz eines Clusters einsehen. Sie können den gesamten belegten logischen Speicherplatz, den gesamten belegten physischen Speicherplatz und den verfügbaren Festplattenspeicher einsehen.

Es besteht die Möglichkeit, sich bei ActiveIQ zu registrieren, um historische Clusterdaten anzuzeigen.

Über image:icon_arrow.gif["Pfeilsymbol"] neben *Capacity* im Dashboard lassen sich Informationen zur Clusterkapazität anzeigen, einschließlich einer Übersicht über die einem Cluster zugeordneten Tiers, etwa Gesamtspeicherplatz, belegter Speicherplatz und verfügbarer Speicherplatz. Außerdem sind Details zu Durchsatz, IOPS und Latenz zu sehen. link:./concepts/capacity-measurements.html["Informationen dazu, wie ONTAP genutzten Storage meldet"].

Über die Kapazitätsansicht kann eine lokale Tier oder eine Cloud Tier hinzugefügt werden. Weitere Informationen finden sich unter link:task_admin_monitor_capacity_in_sm.html["Kapazität eines Clusters anzeigen"].



[[view-the-cluster-network]]
== Clusternetzwerk anzeigen

Im Abschnitt *Network* des ONTAP System Manager Dashboard können Sie die physischen Ports, Netzwerkschnittstellen und storage VMs anzeigen, die Teil des Netzwerks sind.

Die Netzwerkansicht zeigt die Typen der mit dem Netzwerk verbundenen Clients an. Jeder dieser netzwerkverbundenen Clients wird durch eine Zahl dargestellt (zum Beispiel „NVMe/FC 16“). Durch Auswahl der Zahl werden spezifische Details zu jedem dieser Netzwerkelemente angezeigt.

Mit image:icon_arrow.gif["Pfeilsymbol"] neben *Network* im Dashboard lässt sich eine umfassende Vollseitenansicht des Netzwerks anzeigen, die Ports, Netzwerkschnittstellen, Storage VMs und Hosts im Netzwerk umfasst.



[[view-the-cluster-performance]]
== Cluster-Performance anzeigen

Im Abschnitt *Performance* des ONTAP System Manager Dashboard lassen sich Performance-Statistiken anzeigen, die beim Überwachen des Systemstatus und der Effizienz Ihres ONTAP Cluster helfen. Die Statistiken umfassen wichtige Cluster-Performance-Indikatoren wie Latenz, Durchsatz und IOPS, dargestellt als Diagramme.

Die Leistungsansicht zeigt Leistungsstatistiken in verschiedenen Zeitintervallen nach Tag, Stunde, Woche oder Jahr an. Die Clusterleistung lässt sich mithilfe verschiedener Diagramme schnell analysieren, sodass sich Merkmale identifizieren lassen, die eine Optimierung erfordern könnten. Diese Schnellanalyse unterstützt die Entscheidung, wie Workloads hinzugefügt oder verschoben werden können. Auch Spitzenzeiten der Nutzung lassen sich betrachten, um potenzielle Änderungen zu planen.

Die Leistungsansicht zeigt die Gesamtleistungskennzahlen in Bezug auf Latenz, Durchsatz und IOPS an.

Ab Version 9.15.1 ist die Leistungsansicht erweitert und zeigt Diagramme für Lese-, Schreib-, sonstige und Gesamtleistungskennzahlen in Bezug auf Latenz, Durchsatz und IOPS. Zu den sonstigen Kennzahlen zählen alle Operationen, die weder Lese- noch Schreibvorgänge sind.

Die Leistungswerte werden alle 3 Sekunden aktualisiert und das Leistungsdiagramm alle 15 Sekunden. Ein Diagramm wird nicht angezeigt, wenn keine Informationen zur Clusterleistung verfügbar sind.

Über image:icon-expansion-arrows.png["Erweiterungssymbol"] neben *Performance* im Dashboard lässt sich eine ganzseitige Ansicht der Performance Kennzahlen nach Stunde, Tag, Woche, Monat und Jahr anzeigen. Außerdem können Sie einen Bericht der Performance Kennzahlen auf Ihr lokales System herunterladen.
