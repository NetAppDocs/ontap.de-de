= Ändern eines ONTAP Administratorpassworts
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Sie sollten Ihr anfängliches ONTAP Administratorpasswort unmittelbar nach der ersten Anmeldung und anschließend regelmäßig ändern, um die Sicherheit Ihres Clusters zu gewährleisten.

Ab ONTAP 9.20.1 zeigt der System Manager, sofern Ihr Benutzerkonto für Benachrichtigungen zum Passwortablauf konfiguriert ist, 14 Tage vor Ablauf Ihres Passworts eine Warnmeldung an. Die Meldung wird bei jeder Anmeldung aktualisiert und zeigt die verbleibenden Tage an.

.Über diese Aufgabe
Das neue Passwort muss folgende Regeln erfüllen:

* Es darf den Benutzernamen nicht enthalten
* Es muss mindestens acht Zeichen lang sein
* Es muss mindestens einen Buchstaben und eine Zahl enthalten
* Es kann nicht dasselbe sein wie die letzten sechs Passwörter



NOTE: Der  `security login role config modify`Befehl kann verwendet werden, um die Passwortregeln für Konten zu ändern, die einer bestimmten Rolle zugeordnet sind.

.Bevor Sie beginnen
* Sie müssen Cluster- oder SVM-Administrator sein, um Ihr eigenes Passwort zu ändern.
* Sie müssen Cluster-Administrator sein, um das Passwort eines anderen Administrators zu ändern.


.Schritte
Das Ändern Ihres Passworts ist über System Manager oder die ONTAP Befehlszeilenschnittstelle (CLI) möglich.

[role="tabbed-block"]
====
.System Manager
--
. Im System Manager *Cluster > Einstellungen* auswählen.
. Unter *Benutzer und Rollen* können Sie *Benutzer* auswählen.
. Es ist image:icon_kabob.gif["Menü"] neben dem Benutzerkonto auszuwählen, für das das Passwort geändert werden muss, und anschließend *Change password*.
. Neues Passwort eingeben.
. Zur Bestätigung wird das neue Passwort erneut eingegeben und anschließend *Speichern* ausgewählt.


--
.CLI
--
Wenn Sie SVM-Administrator sind, können Sie den  `security login password` Befehl verwenden, um Ihr eigenes Passwort zu ändern. Wenn Sie Cluster-Administrator sind, können Sie den  `security login password` Befehl verwenden, um das Passwort eines beliebigen Administrators zu ändern.

. Ändern eines Administratorpassworts: `security login password -vserver _svm_name_ -username _user_name_`
+
Der folgende Befehl ändert das Kennwort des Administrators `admin1` für die SVM `vs1.example.com`. Danach geben Sie das aktuelle Kennwort sowie das neue Kennwort zur Bestätigung zweimal ein.

+
[listing]
----
vs1.example.com::>security login password -vserver engData -username admin1
Please enter your current password:
Please enter a new password:
Please enter it again:
----
