= Informationen zu NFS-Exporten in ONTAP
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ONTAP steuert den NFS-Client-Zugriff über Exportrichtlinien, die Volumes oder Qtrees zugewiesen sind. Jede Richtlinie enthält Regeln, die definieren, welche Clients auf Daten zugreifen dürfen und welche Berechtigungen sie erhalten.



[[export-policies-and-rules]]
== Exportrichtlinien und Regeln

Eine SVM kann mehrere Exportrichtlinien enthalten. Jede Richtlinie kann null oder mehrere Exportregeln enthalten, die Clientübereinstimmungen und Zugriffsberechtigungen festlegen. Eine leere Richtlinie verweigert jeglichen Zugriff. Eine Exportrichtlinie lässt sich auf mehrere Volumes anwenden.



[[apply-export-policies-to-volumes-and-qtrees]]
== Exportrichtlinien auf Volumes und qtrees anwenden

Einem Volume oder Qtree wird eine Exportrichtlinie zugewiesen, um den Zugriff von NFS-Clients auf diesen Storage zu steuern. Eine einem Volume zugewiesene Richtlinie gilt für die Daten des Volumes; einem Qtree kann direkt eine Richtlinie zugewiesen werden, wenn der Zugriff auf diesen Qtree gesteuert werden muss.



[[volume-junction-paths]]
== Volume Verbindungspfade

Volumes sind im SVM Namespace unter einem Verbindungspfad eingebunden. NFS-Clients verwenden diesen Pfad, um auf die Daten des Volumes zuzugreifen. Der Verbindungspfad kann vom Volume-Namen abweichen.
