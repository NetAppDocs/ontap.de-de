= Verwaltung von MAV geschützten Operationsanforderungen in ONTAP
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Wenn Administratoren in einer MAV-Genehmigungsgruppe (MAV-Administratoren) über eine ausstehende Ausführungsanfrage benachrichtigt werden, müssen sie innerhalb einer festgelegten Frist (Ablauf der Genehmigung) mit einer Genehmigungs- oder Ablehnungsnachricht antworten. Wenn nicht genügend Genehmigungen eingehen, muss der Anfragende die Anfrage löschen und eine neue stellen.

.Über diese Aufgabe
Genehmigungsanfragen werden mit Indexnummern gekennzeichnet, die in E-Mail-Nachrichten und in der Anzeige der Anfragewarteschlange enthalten sind.


NOTE: `multi-admin-verify`Anfragen im Endstatus können automatisch überschrieben oder entfernt werden. Die link:../system-admin/audit-display-log-contents-task.html["Revisionsprotokoll"] kann zur Überprüfung vorheriger Anfragen verwendet werden.


NOTE: Ab ONTAP 9.20.1 können Mitglieder einer konfigurierten Genehmigergruppe für IdP, AD oder LDAP Anfragen genehmigen oder ablehnen, ohne als namentlich genannte Genehmiger aufgeführt zu sein. Änderungen an der Gruppenzugehörigkeit eines Benutzers im Identitätsanbieter werden bei der nächsten erfolgreichen Anmeldung des Benutzers wirksam. Eine Neukonfiguration von MAV ist nicht erforderlich.

Folgende Informationen aus der Anfragewarteschlange können angezeigt werden:

Betrieb:: Die geschützte Operation, für die die Anfrage erstellt wird.
Abfrage:: Das Objekt (oder die Objekte), auf das bzw. die der Benutzer die Operation anwenden möchte.
Status:: Der aktuelle Status des Antrags: ausstehend, genehmigt, abgelehnt, abgelaufen, ausgeführt. Wird ein Antrag von einem Genehmiger abgelehnt, sind keine weiteren Maßnahmen möglich.
Erforderliche Genehmiger:: Die Anzahl der MAV-Administratoren, die die Anfrage genehmigen müssen. Ein Benutzer kann den Parameter required-approvers für die Vorgangsregel festlegen. Wenn ein Benutzer required-approvers für die Regel nicht festlegt, wird der Wert required-approvers aus der globalen Einstellung angewendet.
Ausstehende Genehmiger:: Die Anzahl der MAV-Administratoren, die noch erforderlich sind, um die Anfrage zu genehmigen, damit die Anfrage als genehmigt markiert wird.
Potenzielle Genehmigergruppen:: Ab ONTAP 9.20.1 sind dies die IdP-, Active Directory- oder LDAP-Gruppen, deren Mitglieder berechtigt sind, die Anfrage zu genehmigen oder abzulehnen.
Ablauf der Genehmigung:: Die Frist, innerhalb derer ein MAV-Administrator auf eine Genehmigungsanfrage reagieren muss. Jeder autorisierte Benutzer kann die Genehmigungsfrist für eine Vorgangsregel festlegen. Ist keine Genehmigungsfrist für die Regel festgelegt, wird die Genehmigungsfrist aus der globalen Einstellung angewendet.
Ablauf der Ausführung:: Der Zeitraum, innerhalb dessen der anfragende Administrator den Vorgang abschließen muss. Jeder autorisierte Benutzer kann das Ausführungsablaufdatum für eine Vorgangsregel festlegen. Wenn kein Ausführungsablaufdatum für die Regel festgelegt ist, wird das Ausführungsablaufdatum aus der globalen Einstellung übernommen.
Genehmigte Nutzer:: Die MAV-Administratoren, die den Antrag genehmigt haben.
Benutzer hat sein Veto eingelegt:: Die MAV-Administratoren, die den Antrag abgelehnt haben.
Storage VM (vserver):: Die SVM, der die Anfrage zugeordnet ist. In dieser Version wird nur die admin SVM unterstützt.
Benutzeranfrage:: Der Benutzername des Benutzers, der die Anfrage erstellt hat.
Erstellungszeit:: Der Zeitpunkt, zu dem die Anfrage erstellt wurde.
Genehmigungszeit:: Der Zeitpunkt, zu dem sich der Status der Anfrage auf „genehmigt“ geändert hat.
Kommentar:: Alle Kommentare, die mit der Anfrage in Verbindung stehen.
Zugelassene Benutzer:: Die Liste der Benutzer, die berechtigt sind, die geschützte Operation durchzuführen, für die die Anfrage genehmigt wurde. Wenn `users-permitted`leer ist, kann jeder Benutzer mit den entsprechenden Berechtigungen die Operation durchführen.


[role="tabbed-block"]
====
.System Manager
--
MAV-Administratoren erhalten E-Mails mit Details zur Genehmigungsanfrage, deren Gültigkeitsdauer und einem Link zur Genehmigung oder Ablehnung der Anfrage. Sie können den Genehmigungsdialog über den Link in der E-Mail aufrufen oder in System Manager zu *Events & Jobs > Multi-Admin Requests* navigieren.

Das Fenster *Multi-Admin Requests* ist verfügbar, wenn die Multi-Admin-Verifizierung aktiviert ist, und zeigt ausstehende Anfragen basierend auf der Anmelde-ID des Benutzers und der MAV-Rolle (Genehmiger oder nicht) an. Mit *My Approvals* werden nur die Anfragen aufgelistet, für die der angemeldete Benutzer berechtigt ist zu handeln, einschließlich Anfragen, die über die Mitgliedschaft in einer IdP-, Active Directory- oder LDAP-Genehmigergruppe verfügbar sind.

* Betrieb
* Index (Nummer)
* Status (Ausstehend, Genehmigt, Abgelehnt, Ausgeführt oder Abgelaufen)
+
Wird ein Antrag von einem Genehmiger abgelehnt, sind keine weiteren Maßnahmen möglich.

* Abfrage (beliebige Parameter oder Werte für die angeforderte Operation)
* Anfordernder Benutzer
* Anfrage läuft am
* (Anzahl der) ausstehenden Genehmiger
* Potenzielle Genehmiger (ab ONTAP 9.20.1 umfasst dies Benutzer, die als benannte Genehmiger oder durch Mitgliedschaft in einer berechtigten IdP-, Active Directory- oder LDAP-Genehmigergruppe infrage kommen)


MAV-Administratoren verfügen in diesem Fenster über zusätzliche Steuerungsmöglichkeiten; sie können einzelne Vorgänge oder ausgewählte Gruppen von Vorgängen genehmigen, ablehnen oder löschen. Wenn der MAV-Administrator jedoch der Requesting User ist, kann er seine eigenen Anfragen nicht genehmigen, ablehnen oder löschen.

--
.CLI
--
. Wenn Sie per E-Mail über ausstehende Anfragen benachrichtigt werden, sollten Sie die Indexnummer und die Gültigkeitsdauer der Genehmigung der Anfrage beachten. Die Indexnummer kann auch mithilfe der Optionen *show* oder *show-pending* in der folgenden Tabelle angezeigt werden.
. Den Antrag genehmigen oder ablehnen.
+
[cols="50,50"]
|===
| Wenn Sie Folgendes tun möchten… | Diesen Befehl eingeben 


 a| 
Eine Anfrage genehmigen
 a| 
`security multi-admin-verify request approve _nn_`



 a| 
Einen Antrag ablehnen
 a| 
`security multi-admin-verify request veto _nn_`



 a| 
Alle Anfragen, ausstehende Anfragen oder eine einzelne Anfrage anzeigen
 a| 
`security multi-admin-verify request { show | show-pending } [_nn_]
{ -fields _field1_[,_field2_...] |  [-instance ]  }`

Sie können alle Anfragen in der Warteschlange oder nur ausstehende Anfragen anzeigen. Bei Eingabe der Indexnummer werden nur die Informationen dazu angezeigt. Informationen zu bestimmten Feldern (mithilfe des  `-fields` Parameters) oder zu allen Feldern (mithilfe des  `-instance` Parameters) können angezeigt werden.



 a| 
Eine Anfrage löschen
 a| 
`security multi-admin-verify request delete _nn_`

|===


.Beispiel:
Die folgende Sequenz genehmigt eine Anfrage, nachdem der MAV-Administrator die Anfrage-E-Mail mit der Indexnummer 3 erhalten hat, die bereits eine Genehmigung hat.

[listing]
----
          cluster1::> security multi-admin-verify request show-pending
                                   Pending
Index Operation      Query State   Approvers Requestor
----- -------------- ----- ------- --------- ---------
    3 volume delete  -     pending 1         julia


cluster-1::> security multi-admin-verify request approve 3

cluster-1::> security multi-admin-verify request show 3

     Request Index: 3
         Operation: volume delete
             Query: -
             State: approved

Ab ONTAP 9.20.1 enthält der `security multi-admin-verify request show` Befehl ein `Potential Approver Groups` Feld, in dem alle IdP-, AD- oder LDAP-Gruppen aufgeführt sind, deren Mitglieder berechtigt sind, die Anfrage zu genehmigen oder abzulehnen.
