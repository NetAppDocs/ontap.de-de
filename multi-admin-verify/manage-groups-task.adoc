= ONTAP Administrator-Genehmigungsgruppen für MAV verwalten
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Bevor die Multi-Admin-Verifizierung (MAV) aktiviert wird, ist eine Administrator-Genehmigungsgruppe zu erstellen, die mindestens einen Administrator mit Genehmigungs- oder Vetorecht enthält. Nach der Aktivierung der Multi-Admin-Verifizierung erfordern Änderungen an der Mitgliedschaft der Genehmigungsgruppe die Zustimmung eines der bestehenden berechtigten Administratoren.

.Über diese Aufgabe
Sie können bestehende Administratoren zu einer MAV Gruppe hinzufügen oder neue Administratoren erstellen.

Die MAV-Funktionalität berücksichtigt bestehende Einstellungen der rollenbasierten Zugriffssteuerung (RBAC). Potenzielle MAV-Administratoren müssen über ausreichende Berechtigungen zum Ausführen geschützter Operationen verfügen, bevor sie zu MAV-Administratorgruppen hinzugefügt werden. link:../authentication/create-svm-user-accounts-task.html["Weitere Informationen zu RBAC."]

Sie können MAV so konfigurieren, dass MAV-Administratoren über ausstehende Genehmigungsanfragen benachrichtigt werden. Hierfür ist die Konfiguration von E-Mail-Benachrichtigungen erforderlich, insbesondere der  `Mail From` und  `Mail Server` Parameter, oder diese Parameter können gelöscht werden, um die Benachrichtigung zu deaktivieren. Ohne E-Mail-Benachrichtigungen müssen MAV-Administratoren die Genehmigungswarteschlange manuell prüfen.

Ab ONTAP 9.15.1 ist es möglich, Active Directory (AD)-Benutzer als MAV-Administratoren zu konfigurieren. Der AD-Benutzer muss link:../authentication/grant-access-active-directory-users-groups-task.html["Als ONTAP Administrator konfiguriert"] sein.

Ab ONTAP 9.20.1 können Genehmigungsgruppen auch Identity Provider (IdP)-, Active Directory (AD)- oder LDAP (nsswitch)-Gruuppen umfassen. Zu den unterstützten Gruppentypen gehören Entra ID (ehemals Azure AD), ADFS, AD-Domänengruppen und LDAP-Gruppen.

Änderungen an der Gruppenzugehörigkeit eines Benutzers beim Identitätsanbieter werden bei der nächsten erfolgreichen Anmeldung des Benutzers wirksam. Eine Neukonfiguration von MAV ist nicht erforderlich.


NOTE: Bevor Sie eine IdP-, Active Directory- oder LDAP-Gruppe zu einer MAV-Genehmigungsgruppe hinzufügen können, muss die Gruppe bereits über einen konfigurierten Anmeldezugriff verfügen und in der  `security login group`Tabelle mit einer Rollenzuordnung registriert sein. Die entsprechenden Verfahren sind nachfolgend aufgeführt.



[[system-manager-procedure]]
== System Manager Verfahren

Wenn zum ersten Mal eine MAV-Genehmigungsgruppe erstellt werden soll, bietet die System Manager Vorgehensweise weitere Informationen zu link:enable-disable-task.html#system-manager-procedure["Multi-Admin-Verifizierung aktivieren."]

Eine bestehende Genehmigungsgruppe kann geändert oder eine zusätzliche Genehmigungsgruppe erstellt werden:

. Administratoren für den Erhalt der Multi-Admin-Verifizierung festlegen.
+
.. *Cluster > Einstellungen* auswählen.
.. Die Auswahl von image:icon_arrow.gif["Pfeilsymbol"] erfolgt neben *Benutzer, Gruppen und Rollen.*
.. Unter *Users* erfolgt die Auswahl von image:icon_add.gif["Symbol hinzufügen"].
.. Die Liste kann bei Bedarf angepasst werden.
+
Weitere Informationen sind unter link:../task_security_administrator_access.html["Administratorzugriff kontrollieren."] verfügbar.



. Ab ONTAP 9.20.1 ist vor dem Hinzufügen einer IdP-, AD- oder LDAP-Gruppe als MAV-Genehmiger zunächst eine Registrierung der Gruppe erforderlich, damit in der MAV-Konfiguration auf sie verwiesen werden kann.
+
.. Unter *Gruppen* erfolgt das Hinzufügen einer Gruppe über image:icon_add.gif["Symbol hinzufügen"].
+
Eingabe des Gruppennamens. Das UUID-Feld ist nur für Microsoft Entra-Gruppen erforderlich; andere Identitätsanbieter verwenden den Gruppennamen.

.. Unter *Gruppe-Rollen-Zuordnung* erfolgt die Auswahl von image:icon_add.gif["Symbol hinzufügen"] und der Gruppe sowie die Zuweisung einer Rolle mit ausreichenden Berechtigungen zur Genehmigung von MAV-Anfragen.


. MAV-Genehmigungsgruppe erstellen oder ändern:
+
.. *Cluster > Einstellungen* auswählen.
.. Wählen Sie image:icon_arrow.gif["Pfeilsymbol"] neben *Genehmigung durch mehrere Administratoren* im Abschnitt *Sicherheit* aus. (Das image:icon_gear.gif["Aktionssymbol"]-Symbol wird angezeigt, wenn MAV noch nicht konfiguriert ist.)
+
*** Name: Einen Gruppennamen eingeben.
*** Genehmiger (Benutzer): Auswahl einzelner Genehmiger aus einer Benutzerliste.
*** Genehmiger (Gruppen): Ab ONTAP 9.20.1 können Sie optional eine oder mehrere registrierte IdP-, Active Directory- oder LDAP-Gruppen auswählen.
*** E-Mail-Adresse: E-Mail-Adresse(n) eingeben.
*** Standardgruppe: eine Gruppe auswählen.






Für die Bearbeitung einer bestehenden Konfiguration ist nach der Aktivierung von MAV eine MAV-Genehmigung erforderlich.



[[cli-procedure]]
== CLI Prozedur

. Überprüfen Sie, ob für die  `Mail From` und  `Mail Server` Parameter Werte festgelegt wurden. Folgendes eingeben:
+
`event config show`

+
Die Anzeige sollte in etwa wie folgt aussehen:

+
[listing]
----
cluster01::> event config show
                           Mail From:  admin@localhost
                         Mail Server:  localhost
                           Proxy URL:  -
                          Proxy User:  -
 Publish/Subscribe Messaging Enabled:  true
----
+
Zum Konfigurieren dieser Parameter wird Folgendes eingegeben:

+
`event config modify -mail-from _email_address_ -mail-server _server_name_`

+
Weitere Informationen zu  `event config show` und  `event config modify` finden sich in der link:https://docs.netapp.com/us-en/ontap-cli/search.html?q=event+config["ONTAP-Befehlsreferenz"^].

. Es sind Administratoren zu bestimmen, die an der Multi-Admin-Verifizierung teilnehmen.
+
[cols="50,50"]
|===
| Wenn Sie Folgendes tun möchten… | Diesen Befehl eingeben 


| Aktuelle Administratoren anzeigen  a| 
`security login show`



| Anmeldeinformationen der aktuellen Administratoren ändern  a| 
`security login modify _<parameters>_`



| Neue Administratorkonten erstellen  a| 
`security login create -user-or-group-name _admin_name_ -application ssh -authentication-method password`

|===
+
Weitere Informationen zu `security login show`, `security login modify` und `security login create` in der link:https://docs.netapp.com/us-en/ontap-cli/search.html?q=security+login["ONTAP-Befehlsreferenz"^].

. Ab ONTAP 9.20.1 ist beim Hinzufügen einer IdP-, AD- oder LDAP-Gruppe als MAV-Genehmiger zunächst zu prüfen, ob für die Gruppe der Anmeldezugriff konfiguriert ist; anschließend ist sie für MAV zu registrieren.
+
Falls für die Gruppe noch kein Anmeldezugriff konfiguriert ist, ist Folgendes einzugeben:

+
`security login create -user-or-group-name _group_name_ -application http|ssh -authentication-method domain|nsswitch|saml|oauth2 -role _role_`

+
Anschließend wird die Gruppe registriert, damit in der MAV Konfiguration auf sie verwiesen und sie einer Rolle zugeordnet werden kann:

+
`security login group create -vserver _svm_name_ -name _group_name_ [-uuid _uuid_]`

+
`security login group role-mapping create -group-id _group_id_ -role _role_`

+
Der `-uuid` Parameter ist nur für Microsoft Entra ID-Gruppen erforderlich. Active Directory-Domänengruppen, ADFS/SAML-Gruppen und LDAP-(nsswitch)-Gruuppen werden nur anhand des Namens identifiziert.

+
*Beispiel:* Die folgenden Befehle registrieren die Active Directory-Gruppe `mydomain\mav_approvers` für MAV und ordnen sie der `admin` Rolle zu.

+
[listing]
----
cluster-1::> security login group create -vserver cluster-1 -name mydomain\mav_approvers
cluster-1::> security login group show -vserver cluster-1

     Vserver: cluster-1
  Group Name: mydomain\mav_approvers
    Group ID: 1
  Group UUID: -
     Comment: -

cluster-1::> security login group role-mapping create -group-id 1 -role admin
----
+
Weitere Informationen zu  `security login group create` und  `security login group role-mapping create` finden sich in der link:https://docs.netapp.com/us-en/ontap-cli/search.html?q=security+login+group["ONTAP-Befehlsreferenz"^].

. Die MAV-Genehmigungsgruppe erstellen:
+
`security multi-admin-verify approval-group create [ -vserver _svm_name_] -name _group_name_ [-approvers _approver1_[,_approver2_…]] [-groups _group1_[,_group2_…]] [[-email _address1_], _address1_...]`

+
** `-vserver` - Nur die Admin-SVM wird in dieser Version unterstützt.
** `-name` - Der MAV Gruppenname, maximal 64 Zeichen.
** `-approvers` - Die Liste eines oder mehrerer einzelner Genehmiger. Für AD-Benutzer gilt das Format `domain\user`. Beispielsweise `mydomain\pavan`.
** `-groups` - Die Liste einer oder mehrerer IdP-, AD- oder LDAP-Gruppen, die in die Genehmigungsgruppe aufgenommen werden sollen. Jede Gruppe muss bereits in der `security login group`Tabelle mit einer Rollenzuordnung registriert sein.
** `-email` - Eine oder mehrere E-Mail-Adressen, die benachrichtigt werden, wenn eine Anfrage erstellt, genehmigt, abgelehnt oder ausgeführt wird.
+
*Beispiel:* Der folgende Befehl erstellt eine MAV-Gruppe mit zwei einzelnen Genehmigern und einer Entra ID Gruppe.

+
[listing]
----
cluster-1::> security multi-admin-verify approval-group create -name mav-grp1 -approvers pavan,julia -groups entra-group-mav-approvers -email pavan@myfirm.com,julia@myfirm.com
----


. Gruppenerstellung und Mitgliedschaft überprüfen:
+
`security multi-admin-verify approval-group show`

+
*Beispiel:*

+
[listing]
----
cluster-1::> security multi-admin-verify approval-group show
Vserver  Name        Approvers        Approver Groups                  Email
-------  ---------------- ------------------  ------------------------------- ------------------------------------------------------------
svm-1    mav-grp1   pavan,julia      entra-group-mav-approvers        pavan@myfirm.com,julia@myfirm.com
----


Diese Befehle dienen zur Änderung der ursprünglichen MAV Gruppenkonfiguration.

*Hinweis:* Alle erfordern die Genehmigung durch den MAV-Administrator, bevor sie ausgeführt werden.

[cols="50,50"]
|===
| Wenn Sie Folgendes tun möchten… | Diesen Befehl eingeben 


| Gruppenmerkmale oder vorhandene Mitgliederinformationen ändern  a| 
`security multi-admin-verify approval-group modify [-vserver _svm_name_] -name _group_name_ [-approvers _approver1_[,_approver2_…]] [-groups _group1_[,_group2_…]] [[-email _address1_], _address1_...]`



| Mitglieder hinzufügen oder entfernen  a| 
`security multi-admin-verify approval-group replace [-vserver _svm_name_] -name _group_name_ [-approvers-to-add _approver1_[,_approver2_…]][-approvers-to-remove _approver1_[,_approver2_…]] [-groups-to-add _group1_[,_group2_…]][-groups-to-remove _group1_[,_group2_…]]`



| Gruppe löschen  a| 
`security multi-admin-verify approval-group delete [-vserver _svm_name_] -name _group_name_`

|===
