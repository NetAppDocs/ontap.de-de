= Informationen zur ONTAP Unterstützung für FC-SP-3-Sicherheit
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Ab ONTAP 9.20.1 unterstützt ONTAP Authentifizierung und Verschlüsselung nach Fibre Channel Security Protocol 3 (FC-SP-3) für sichere Broadcom Hostbusadapter (HBAs) auf bestimmten ONTAP Systemen. FC-SP-3 bietet Verschlüsselung auf Hardware-Ebene und Geräteauthentifizierung, um Daten auf der Übertragungsstrecke zwischen FC- und NVMe/FC-Hosts sowie ONTAP Storage-Systemen vor Abfangen, Manipulation und unberechtigtem Zugriff zu schützen, bei gleichbleibender Performance und in Übereinstimmung mit den T11 FC-Sicherheitsstandards.

Die folgenden sicheren HBAs von Broadcom unterstützen FC-SP-3:

* Zielkarten: LPe38104
* Initiatorkarten: LPe38102 (64G), LPe37102 (32G)


Mit link:https://hwu.netapp.com/["NetApp Hardware Universe"^] können Sie überprüfen, ob Ihr spezifisches ONTAP System die erforderlichen HBAs unterstützt.

Sie können auch den `fcp adapter show -fields transport-security-supported`Befehl verwenden, um zu überprüfen, ob Ihr HBA FC-SP-3 unterstützt. Das Feld *transport-security-supported* ist *true*, wenn FC-SP-3 unterstützt wird.



[[enable-fc-sp-3-support]]
== Aktivierung der FC-SP-3-Unterstützung

Wenn Ihre Konfiguration FC-SP-3 unterstützt, kann es aktiviert werden, wenn Sie eine Netzwerkschnittstelle (LIF) link:../networking/create_a_lif.html["erstellen"] oder link:../networking/modify_a_lif.html["ändern"], indem Sie den  `-fc-transport-security option` auf *mandatory* oder *preferred* setzen. Die Einstellung *mandatory* verhindert, dass Hosts, die FC-SP-3 nicht unterstützen, auf das Storage-System zugreifen. Mit der Einstellung *preferred* versucht ONTAP, eine FC-SP-3-Verbindung herzustellen, während der Hostzugriff weiterhin möglich ist, wenn FC-SP-3 nicht eingerichtet werden kann.
