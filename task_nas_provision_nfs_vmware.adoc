= NFS-Speicher für VMware-Datenspeicher mit ONTAP System Manager bereitstellen
:hardbreaks:
:toclevels: 1
:allow-uri-read: 
:toclevels: 1
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Vor der Verwendung von ONTAP tools for VMware vSphere zur Bereitstellung von NFS Volumes auf einem ONTAP basierten Speichersystem für ESXi Hosts muss NFS mit System Manager für ONTAP 9.7 oder höher aktiviert werden.

Nach der Erstellung eines link:task_nas_enable_linux_nfs.html["NFS-fähige Storage-VM"] in System Manager können Sie anschließend NFS Volumes bereitstellen und Datastores mit ONTAP tools for VMware vSphere verwalten.

Stellen Sie sicher, dass Sie die  https://imt.netapp.com/matrix/["NetApp Interoperabilitätsmatrix"^] prüfen, um die Kompatibilität zwischen Ihren aktuellen ONTAP und ONTAP tools for VMware vSphere Versionen zu bestätigen.

Informationen zum Einrichten des NFS-Zugriffs für ESXi-Hosts auf Datenspeicher mithilfe von System Manager Classic (für ONTAP 9.7 und frühere Versionen) sind unter https://docs.netapp.com/us-en/ontap-system-manager-classic/nfs-config-esxi/index.html["NFS Konfiguration für ESXi – Übersicht"^]

Weitere Informationen finden Sie unter  https://docs.netapp.com/us-en/netapp-solutions/virtualization/vsphere_ontap_ontap_for_vsphere.html["TR-4597: VMware vSphere für ONTAP"^] und dem  https://docs.netapp.com/us-en/ontap-tools-vmware-vsphere-10/["ONTAP tools für VMware vSphere Dokumentation"^].
