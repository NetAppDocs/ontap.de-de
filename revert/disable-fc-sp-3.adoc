= Deaktivierung von FC-SP-3 auf FC LIFs vor dem Zurücksetzen von ONTAP 9.20.1
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Ab ONTAP 9.20.1 unterstützt ONTAP die Authentifizierung und Verschlüsselung mit Fibre Channel Security Protocol 3 (FC-SP-3) unter Verwendung sicherer Broadcom Host-Bus-Adapter (HBAs) mit AFF und FAS Systemen. Wenn FC- oder NVMe/FC-Netzwerkschnittstellen (LIFs) auf Ihrem ONTAP System für FC-SP-3 aktiviert sind, müssen Sie FC-SP-3 deaktivieren, bevor Sie zu ONTAP 9.19.1 zurückkehren.

.Schritte
. Überprüfung der FC-SP-3 Konfiguration auf Ihren LIFs:
+
[source, cli]
----
network interface show -fields fc-transport-security
----
. Wenn der Status des Feldes *transport-security-state* nicht verfügbar ist, sind keine weiteren Maßnahmen erforderlich. Wenn der Status *mandatory* oder *preferred* ist, ist er in *disabled* zu ändern:
+
[source, cli]
----
network interface modify -vserver <vserver_name> -lif <lif_name> -fc-transport-security disabled
----
. Prüfung, ob FC-SP-3 auf den zuvor aktivierten LIFs deaktiviert ist:
+
[source, cli]
----
network interface show -fields fc-transport-security
----
