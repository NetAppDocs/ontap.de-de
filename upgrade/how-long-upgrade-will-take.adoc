= ONTAP Richtlinien zur Dauer des ONTAP Upgrades
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Es ist mit mindestens 30 Minuten für die Vorbereitungsschritte eines ONTAP Upgrades, 60 Minuten für das Upgrade jedes HA Paars und mindestens 30 Minuten für die Nachbereitungsschritte zu rechnen.


NOTE: Wenn Sie NetApp Encryption mit einem externen Schlüsselverwaltungsserver und dem Key Management Interoperability Protocol (KMIP) verwenden, sollten Sie für jedes HA-Paar mit einer Upgrade-Dauer von über einer Stunde rechnen. Diese zusätzliche Zeit gilt nicht für ein automatisiertes, unterbrechungsfreies Upgrade ab ONTAP 9.20.1, wenn der Cluster einen externen KMIP-Schlüsselmanager verwendet, sich nicht in einer MetroCluster Konfiguration befindet und der HA-Partner die Schlüssel bereitstellen kann. Ab ONTAP 9.20.1 stellen diese Cluster die Schlüssel vom HA-Partner wieder her. Weitere Informationen finden Sie unter xref:../encryption-at-rest/configure-external-key-management-overview-concept.html#intracluster-key-sharing[Clusterinterner Schlüsselaustausch]. Beim Upgrade auf ONTAP 9.20.1 werden die Schlüssel weiterhin vom Schlüsselserver wiederhergestellt, daher ist für dieses Upgrade mit einer Dauer von über einer Stunde pro HA-Paar zu rechnen.

Diese Richtlinien zur Upgrade-Dauer basieren auf typischen Konfigurationen und Arbeitslasten. Diese Richtlinien ermöglichen eine Schätzung der Zeit, die für ein unterbrechungsfreies Upgrade in Ihrer Umgebung erforderlich ist. Die tatsächliche Dauer des Upgrade-Prozesses hängt von Ihrer individuellen Umgebung und der Anzahl der Nodes ab.
