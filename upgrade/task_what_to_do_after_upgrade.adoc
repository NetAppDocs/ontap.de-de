= ONTAP Verifizierungsworkflow nach dem Upgrade
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Nach dem Upgrade von ONTAP sind mehrere Aufgaben erforderlich, um die Einsatzbereitschaft Ihres Clusters zu überprüfen.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["Eins"]Ihr Cluster wird überprüft.
[role="quick-margin-para"]
Nach dem Upgrade von ONTAP sollten Sie link:task_verify_cluster_after_upgrade.html["Clusterversion, Clusterzustand und Speicherzustand überprüfen"]. Wenn Sie eine MetroCluster FC-Konfiguration verwenden, ist außerdem zu überprüfen, ob der Cluster für die automatische ungeplante Umschaltung aktiviert ist.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["Zwei"]Es wird überprüft, ob alle LIFs auf den Home-Ports sind.
[role="quick-margin-para"]
Während eines Neustarts wurden möglicherweise einige LIFs auf ihre zugewiesenen Failover-Ports migriert. Nach dem Upgrade eines Clusters ist es erforderlich, link:task_enabling_and_reverting_lifs_to_home_ports_post_upgrade.html["Alle LIFs, die sich nicht auf ihren Heimatports befinden, aktivieren und zurücksetzen"].

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["Drei"]Spezielle, für Ihren Cluster geltende Besonderheiten sind zu berücksichtigen.
[role="quick-margin-para"]
Falls bestimmte Konfigurationen in Ihrem Cluster vorhanden sind, müssen Sie möglicherweise link:concept_special_configurations_post_checks.html["Nach dem Upgrade sind zusätzliche Schritte erforderlich."].

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png["Vier"]Das Disk Qualification Package (DQP) wird aktualisiert.
[role="quick-margin-para"]
Die DQP wird nicht im Rahmen eines ONTAP Upgrades aktualisiert. Nach dem Upgrade ist link:concept_when_you_need_to_update_the_disk_qualification_package.html["das DQP aktualisieren"] erforderlich.
