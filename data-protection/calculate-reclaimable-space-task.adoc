= Wiederherstellbaren Speicherplatz vor dem Löschen von Snapshots berechnen
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Sie können Snapshots auswählen, die Sie löschen möchten, und den zurückgewinnbaren Speicherplatz berechnen, bevor Sie sie löschen.

In Releases vor ONTAP 9.20.1 wird die Berechnung des freigebbaren Speicherplatzes auf FlexVol Volumes unterstützt, und für FlexGroup Volumes ist eine manuelle Zusammenführung der Snapshot-Nutzung über die einzelnen FlexGroup Teil-Volumes erforderlich. Ab ONTAP 9.20.1 kann der freigebbare Speicherplatz für Snapshots in FlexGroup Volumes berechnet werden.

.Schritte
Diese Aufgabe kann über den System Manager oder die ONTAP CLI ausgeführt werden.

[role="tabbed-block"]
====
.System Manager
--
. *Speicher > Volumes* auswählen.
. Das Volume auswählen, von dem Snapshots gelöscht werden sollen.
. *Schnappschüsse* auswählen.
. Einen oder mehrere Schnappschüsse auswählen.
. Auf *Wiederverwertbarer Speicherplatz berechnen* klicken.


--
.CLI
--
. Berechnung des zurückgewinnbaren Speicherplatzes:
+
`volume snapshot compute-reclaimable -vserver <svm_name> -volume <volume_name> -snapshots <snap1,snap2,snap3>`
