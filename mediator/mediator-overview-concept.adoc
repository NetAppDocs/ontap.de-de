= Informationen zu ONTAP Mediator für MetroCluster IP und SnapMirror active sync
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ONTAP Mediator unterstützt SnapMirror active sync und MetroCluster IP, indem ein persistenter und geschützter Speicher für Metadaten zur Hochverfügbarkeit (HA) bereitgestellt wird, eine synchrone Abfrage des Node-Systemstatus zur Unterstützung der Quorumbestimmung erfolgt und ein Ping-Proxy für die Controller-Verfügbarkeit bereitgestellt wird.

ONTAP Mediator läuft auf einem Linux-Host in einer dritten Ausfalldomäne, getrennt von Ihren ONTAP Clustern, und stellt dort einen persistenten, geschützten Speicher für HA-Metadaten bereit. ONTAP nutzt diesen Speicher zusammen mit der Systemstatusabfrage und den Ping Proxy Funktionen des Mediators, um SnapMirror Active Sync Beziehungen und MetroCluster IP Konfigurationen zu überwachen.

* ONTAP Mediator nutzt die Knotenverwaltungs-LIF und die Clusterverwaltungs-LIF, um über mehrere redundante Pfade mit jedem Cluster zu kommunizieren. Dadurch kann ONTAP zwischen einem vollständigen Standortausfall und dem Ausfall einer einzelnen InterSwitch Link (ISL) unterscheiden.
* Bei SnapMirror active sync behandelt ONTAP den Peer als nicht erreichbar, wenn ein Cluster die Verbindung sowohl zu seinem Peer als auch zu ONTAP Mediator verliert, und kann automatisch auf die verbleibende Kopie umschalten.
* In MetroCluster IP-Konfigurationen unterstützt ONTAP Mediator einen Mediator-gestützten automatischen ungeplanten Switchover (MAUSO), indem er Statusinformationen über die MetroCluster Knoten speichert und dabei hilft, im Fehlerfall die geeignete Vorgehensweise zu bestimmen.


Informationen zur Installation oder Aktualisierung der On-Premises Version von ONTAP Mediator finden Sie in der link:https://docs.netapp.com/us-en/ontap-mediator/index.html["ONTAP Mediator Dokumentation"^]

Informationen zum ONTAP Cloud Mediator, der ab ONTAP 9.17.1 verfügbar ist, bietet die link:../snapmirror-active-sync/index.html["SnapMirror active sync Dokumentation"].
