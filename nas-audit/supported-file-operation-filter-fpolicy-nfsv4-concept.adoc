= Unterstützte FPolicy Dateioperationen und Filter für NFSv4 in ONTAP
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Bei der Konfiguration Ihres FPolicy Ereignisses ist zu beachten, dass für die Überwachung von NFSv4-Dateizugriffsvorgängen nur bestimmte Kombinationen von Dateivorgängen und Filtern unterstützt werden.

Ab ONTAP 9.15.1 unterstützt FPolicy das NFSv4.1 Protokoll.

Ab ONTAP 9.19.1 können Administratoren die Verfügbarkeit von NFSv4.2 auf SVM-Ebene steuern, indem sie das Protokoll für einzelne Storage-VMs entweder über System Manager, die CLI oder REST API aktivieren oder deaktivieren.

Ab ONTAP 9.20.1 unterstützt FPolicy die Überwachung von NFSv4.2-Dateizugriffsereignissen, einschließlich neuer Dateivorgänge für Schreibvorgänge mit erweiterten Attributen (xattr) und Sicherheitslabelfiltern für Labeled NFS-Aktivitäten. Weitere Informationen zu link:../nfs-admin/enable-disable-nfs-task.html["NFS für ONTAP SVMs aktivieren oder deaktivieren"].


NOTE: Sicherheitslabel-Filter (`setattr_with_security_label_change` und `getattr_with_security_label_read`) erfordern, dass NFSv4.2-Sicherheitslabels (Labeled NFS) auf der SVM aktiviert sind. Weitere Informationen zu link:../nfs-admin/enable-nfsv42-security-labels-task.html["Aktivierung von NFSv4.2 Sicherheitskennzeichnungen"]. `getxattr` und `listxattrs` sind schreibgeschützte Operationen und werden nicht von FPolicy überwacht.
