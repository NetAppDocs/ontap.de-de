= Ändern der Cloud-Abrufrichtlinie eines Volumes
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
FabricPool Cloud-Datenabruf wird durch Abrufrichtlinien gesteuert, die festlegen, wann Daten in die lokale Ebene zurückgeschrieben werden. Lesemuster können entweder sequenziell oder zufällig sein.

Wenn beispielsweise die Volume-Tiering-Richtlinie „Auto“ verwendet wird und kalte Blöcke sequenziell gelesen werden, bleiben diese kalt und verbleiben auf der Cloud-Tier. Für die meisten Clientanwendungen ist dies erwünschtes Verhalten und verhindert, dass bei den für Antiviren- und Analyseanwendungen typischen Tiefenscans kalte Daten zurück auf die lokale Tier geschrieben werden.

Ab ONTAP 9.8 kann die Cloud-Abrufrichtlinie eines Volumes geändert werden, um das link:tiering-policies-concept.html#how-cloud-retrieval-policies-work-with-tiering-policies["Standard Cloud Retrieval"] Verhalten zu überschreiben.

.Bevor Sie beginnen
* Die Änderung eines Volumes mit der  `-cloud-retrieval-policy` Option erfordert ONTAP 9.8 oder höher.
* Für diese Operation ist die erweiterte Berechtigungsebene erforderlich.
* Das Verhalten von Tiering-Richtlinien mit  `-cloud-retrieval-policy` sollte verstanden werden.
+
link:tiering-policies-concept.html#how-cloud-retrieval-policies-work-with-tiering-policies["Wie Cloud-Abrufrichtlinien mit Tiering-Richtlinien funktionieren"]



.Schritt
. Die Cloud-Abrufrichtlinie für ein vorhandenes Volume kann mit dem  `volume modify` Befehl und der  `-cloud-retrieval-policy` Option geändert werden:
+
[listing]
----
volume create -volume <volume_name> -vserver <vserver_name> - tiering-policy <policy_name> -cloud-retrieval-policy
----
+
[listing]
----
vol modify -volume fp_volume4 -vserver vs0 -cloud-retrieval-policy promote
----
