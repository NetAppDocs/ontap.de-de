= Einen ONTAP FabricPool Spiegel entfernen
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Ein FabricPool Spiegel kann entfernt werden, wenn keine Replikation eines Objektspeichers mehr erforderlich ist.

.Bevor Sie beginnen
Der primäre Objektspeicher muss betriebsbereit sein, andernfalls schlägt der Befehl fehl.


WARNING: Dieser Vorgang löscht dauerhaft alle Objekte im Objektspeicher-Container und kann nicht rückgängig gemacht werden. Die Objektlöschung läuft nach Abschluss des Entspiegelungsvorgangs im Hintergrund weiter. Der Container sollte erst wiederverwendet oder einer anderen Zweckbestimmung zugeführt werden, nachdem der Hintergrundlöschprozess abgeschlossen ist.

.Schritt
. Einen Objektspeicher-Spiegel in einem FabricPool mit dem  `storage aggregate object-store unmirror -aggregate` Befehl entfernen.
+
[listing]
----
cluster1::> storage aggregate object-store unmirror -aggregate aggr1
----
