= Löschen eines ONTAP S3 Bucket mit Objekten
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Ab ONTAP 9.20.1 können Sie Löschvorgänge für Buckets auf Objektspeicher-Servern planen, um Buckets zu entfernen, ohne sie zuvor zu leeren. Dies geschieht mithilfe eines konfigurierbaren, auf Aufbewahrung basierenden Wiederherstellungsfensters, das die Bucket-Wiederherstellung vor Ablauf des Aufbewahrungsintervalls ermöglicht.

Die Möglichkeit, nicht leere Buckets zu löschen, vereinfacht die Außerbetriebnahme von Buckets, da eine manuelle Bereinigung Objekt für Objekt vor dem Entfernen eines Buckets vermieden wird, der Ablaufrückstand reduziert wird und die Kapazität schneller wiederverwendbar ist.

.Bevor Sie beginnen
* Sie müssen Cluster-Administrator oder SVM-Administrator sein.
* Sie müssen sich auf der erweiterten Berechtigungsstufe befinden.




[[delete-a-bucket-that-contains-objects]]
== Löschen eines Buckets, der Objekte enthält

Sie können einen Bucket zur Löschung planen, ohne ihn vorher zu leeren, indem Sie ein Aufbewahrungsintervall festlegen. Standardmäßig beträgt die Aufbewahrungsdauer 12 Stunden.

.Schritte
Diese Aufgabe kann über den System Manager oder die ONTAP CLI ausgeführt werden.

[role="tabbed-block"]
====
.System Manager
--
. Unter *Storage > Buckets* ist der Bucket zu finden, der gelöscht werden soll.
. Neben dem Bucket-Namen können Sie *Delete* auswählen.
. Wenn der Bucket nicht leer ist, ist im Fenster *Delete Bucket* die Option zum Löschen der Daten und zum Leeren des Buckets auszuwählen, und anschließend ist *Delete* auszuwählen.


--
.CLI
--
. Das Aufbewahrungsintervall angeben, nach dessen Ablauf der Bucket endgültig gelöscht wird:
+
`object-store-server create -vserver <SVM name> -bucket-delete-retention-hours <integer>`

. Einleitung des Zeitplans für die Bucket-Löschung:
+
`object-store-server bucket delete -bucket <bucket name> -delete-objects tru`e



--
====


[[recover-a-deleted-bucket]]
== Einen gelöschten Bucket wiederherstellen

Wenn ein Bucket versehentlich gelöscht wird, können Sie ihn während der von Ihnen festgelegten Aufbewahrungsfrist mithilfe der ONTAP CLI wiederherstellen.

. Ein gelöschter Bucket lässt sich mit dem folgenden Befehl wiederherstellen:
+
`object-store-server bucket recover-deleted-bucket -bucket <bucket name>`
