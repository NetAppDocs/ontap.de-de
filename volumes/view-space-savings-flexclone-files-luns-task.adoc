= ONTAP Speicherplatzeinsparungen mit FlexClone-Dateien und FlexClone-LUNs anzeigen
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Sie können den Prozentsatz des durch Block-Sharing auf einem Volume mit FlexClone Dateien und FlexClone LUNs eingesparten Speicherplatzes anzeigen. Dies kann Teil der Kapazitätsplanung sein.

.Schritte
. Anzeige der durch FlexClone Dateien und FlexClone LUNs erzielten Speicherplatzersparnis:
+
[source, cli]
----
volume show -volume <vol_name> -vserver <SVM> -fields used, sis-space-saved, dedupe-space-saved, compression-space-saved
----
+
[NOTE]
====
Wenn Sie diesen Befehl auf einem deduplizierungsfähigen FlexVol Volume ausführen, können Sie den durch Deduplizierung sowie durch FlexClone Dateien und LUNs eingesparten Speicherplatz anzeigen.

====
