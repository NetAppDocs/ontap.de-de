= Aktivieren der ONTAP Unterstützung für die maximale Größe großer Verzeichnisse
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Ab ONTAP 9.20.1 können Sie die Unterstützung für eine größere maximale Verzeichnisgröße aktivieren und konfigurieren, entweder beim Erstellen eines Volumes oder beim Ändern eines vorhandenen Volumes. Dadurch können Verzeichnisse bis zu ca. 25 Millionen Dateien, Ordner und andere Einträge enthalten, basierend auf einer maximalen Verzeichnisgröße von 4 GB.

[CAUTION]
====
Nach der Erhöhung der maximalen Verzeichnisgröße lässt sie sich nicht wieder verringern, ohne das oder die betroffenen Verzeichnisse auf dem Volume neu zu erstellen.

====
.Bevor Sie beginnen
Bevor Sie ein Volume erstellen oder ändern, um eine größere maximale Verzeichnisgröße zu unterstützen, ist sicherzustellen, dass Sie Cluster- oder SVM-Administrator sind.



[[create-a-new-volume]]
== Ein neues Volume erstellen

Sie können beim Erstellen eines neuen Volume eine größere maximale Verzeichnisgröße festlegen.

.Schritte
. Erstellung eines Volume mit aktivierter Unterstützung für die größere maximale Verzeichnisgröße:
+
[source, cli]
----
volume create -vserver <svm_name> -volume <volume_name> -aggregate <aggr_name> -is-dir-index-transfer-enabled true
----
+
.Beispiel
[listing]
----
volume create -vserver vs1 -volume big_dir1 -aggregate aggr1 -is-dir-index-transfer-enabled true
----
. Erhöhung der maximalen Verzeichnisgröße auf bis zu 4 GB:
+
[source, cli]
----
volume modify -vserver <svm_name> -volume <volume_name> -maxdir-size <dir_size>
----
+
.Beispiel
[listing]
----
volume modify -vserver vs1 -volume big_dir1 -maxdir-size 4GB
----




[[modify-an-existing-volume]]
== Ein vorhandenes Volume ändern

Beim Ändern eines vorhandenen Volumes lässt sich eine größere maximale Verzeichnisgröße festlegen.

.Schritte
. Aktivierung der Unterstützung für die größere maximale Verzeichnisgröße auf einem vorhandenen Volume:
+
[source, cli]
----
volume modify -vserver <svm_name> -volume <volume_name> -is-dir-index-transfer-enabled true
----
+
.Beispiel
[listing]
----
volume modify -vserver vs2 -volume data_vol -is-dir-index-transfer-enabled true
----
. Erhöhung der maximalen Verzeichnisgröße auf bis zu 4 GB:
+
[source, cli]
----
volume modify -vserver <svm_name> -volume <volume_name> -maxdir-size <dir_size>
----
+
.Beispiel
[listing]
----
volume modify -vserver vs2 -volume data_vol -maxdir-size 4GB
----
