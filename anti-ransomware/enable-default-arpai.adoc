= ONTAP ARP/AI ist in neuen Volumes standardmäßig aktiviert
:hardbreaks:
:toclevels: 1
:allow-uri-read: 
:toclevels: 1
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
Ab ONTAP 9.16.1 können Storage-VMs (SVMs) so konfiguriert werden, dass neue Volumes standardmäßig mit Autonomous Ransomware Protection with AI (ARP/AI) aktiviert sind. Ab ONTAP 9.18.1 wird ARP/AI link:support-arpai.html["Unterstützte Systeme"] nach einer 12-stündigen Kulanzfrist automatisch auf Clusterebene aktiviert. Dieses Verfahren ist anzuwenden, wenn ARP/AI standardmäßig für neue Volumes auf SVM-Ebene statt auf Clusterebene aktiviert werden soll.

Für ONTAP 9.17.1 und früher ist die Konfiguration auf SVM-Ebene die einzige Möglichkeit, ARP standardmäßig auf neuen Volumes zu aktivieren.


NOTE: Wenn Sie ONTAP 9.15.1 oder eine frühere Version verwenden, siehe link:enable-default-arp.html["ARP standardmäßig in neuen Volumes aktivieren"].


NOTE: Für ONTAP 9.13.1 bis 9.17.1 verwenden FlexGroup Volumes das frühere ARP-Modell und benötigen eine Lernphase. Siehe link:enable-default-arp.html["ARP standardmäßig in neuen Volumes aktivieren"].

.Über diese Aufgabe
Auf Systemen, auf denen ARP/AI nicht automatisch auf Clusterebene aktiviert ist, werden neue Volumes standardmäßig mit deaktivierter ARP/AI-Funktionalität erstellt. ARP/AI muss aktiviert und so konfiguriert werden, dass es für neue in der SVM erstellte Volumes standardmäßig aktiviert ist.

Vorhandene Volumes ohne aktiviertes ARP/AI ändern ihren ARP/AI-Aktivierungsstatus nicht automatisch, wenn die SVM-Standardeinstellung geändert wird. Die in diesem Verfahren beschriebene SVM-Einstellung betrifft nur neue Volumes. Informationen dazu, wie link:enable-arpai.html["ARP/AI für bestehende Volumes aktivieren"].

[[arp-enablement-default-behavior-table]]
Nach der Aktivierung des autonomen Ransomware-Schutzes kann es je nach Umgebung und ONTAP Version zu einer Übergangsphase kommen:

[cols="25,25,50"]
|===
| Volumentyp | ONTAP Version | Verhalten nach der Aktivierung 


.2+| NAS FlexGroup | ONTAP 9.18.1 und höher | ARP/KI ist sofort ohne Lernphase aktiv 


| ONTAP 9.13.1 bis 9.17.1 | ARP startet im Lernmodus für 30 Tage 


.2+| NAS FlexVol | ONTAP 9.16.1 und höher | ARP/KI ist sofort ohne Lernphase aktiv 


| ONTAP 9.10.1 bis 9.15.1 | ARP startet im Lernmodus für 30 Tage 


| SAN-Volumes | ONTAP 9.17.1 und höher | ARP/AI wird sofort aktiv und leitet eine Evaluierungsphase ein, um einen geeigneten Alarmschwellenwert festzulegen, bevor von einem anfänglich konservativen Schwellenwert umgeschaltet wird. 
|===
.Bevor Sie beginnen
Bevor ARP/AI standardmäßig aktiviert wird, muss sichergestellt sein, dass Ihre Umgebung Folgendes aufweist:

.NAS-spezifische Anforderungen
* Eine Storage-VM (SVM) mit aktiviertem NFS- oder SMB-Protokoll (oder beiden).
* Ein aktives link:../concepts/namespaces-junction-points-concept.html["Verbindungspfad"] für das Volume.


.SAN-spezifische Anforderungen
* Eine Storage VM (SVM) mit aktiviertem iSCSI, FC oder NVMe Protokoll.


.Allgemeine Anforderungen
* Die link:index.html#licenses-for-autonomous-ransomware-protection["korrekte Lizenz"] für Ihre ONTAP Version.
* (Empfohlen) Multi-Admin-Verifizierung (MAV) aktiviert (ONTAP 9.13.1 und höher). Siehe link:../multi-admin-verify/enable-disable-task.html["Multi-Admin-Verifizierung aktivieren"].


.Schritte
Sie können den System Manager oder die ONTAP CLI verwenden, um ARP/AI standardmäßig für neue Volumes auf SVM-Ebene zu aktivieren.

[role="tabbed-block"]
====
.System Manager
--
. *Speicher* oder *Cluster* (je nach Umgebung) auswählen, *Speicher-VMs* auswählen und die Speicher-VM auswählen, die die Volumes enthält, die mit ARP/AI geschützt werden sollen.
. Navigieren Sie zum Tab *Einstellungen*. Unter *Sicherheit* die Kachel *Anti-ransomware* suchen und dann image:icon_pencil.gif["Bearbeiten-Symbol"] auswählen.
. Aktivieren Sie das Kontrollkästchen, um Anti-Ransomware (ARP/AI) zu aktivieren. Aktivieren Sie das zusätzliche Kontrollkästchen, um ARP/AI auf allen geeigneten Volumes in der Storage-VM zu aktivieren.
+

NOTE: ARP/AI wechselt sofort in den aktiven Modus; eine Lernphase ist nicht erforderlich.



--
.CLI
--
.Eine bestehende SVM so modifizieren, dass ARP/AI in neuen Volumes standardmäßig aktiviert ist
[source, cli]
----
vserver modify -vserver <svm_name> -anti-ransomware-default-volume-state enabled
----
.Eine neue SVM mit standardmäßig aktiviertem ARP/AI für neue Volumes erstellen
[source, cli]
----
vserver create -vserver <svm_name> -anti-ransomware-default-volume-state enabled
----
.Den ARP/AI-Status überprüfen
[source, cli]
----
security anti-ransomware volume show
----
--
