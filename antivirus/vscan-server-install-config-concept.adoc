= ONTAP Vscan Serverinstallation und -konfiguration
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Ein oder mehrere Vscan Server werden eingerichtet, damit die Dateien auf Ihrem System auf Viren überprüft werden. Die vom Anbieter bereitgestellten Anweisungen dienen zur Installation und Konfiguration der Antivirensoftware auf dem Server.

Für die Installation und Konfiguration des ONTAP Antivirus Connector dienen die Anweisungen in der von NetApp bereitgestellten README-Datei. Alternativ können die link:install-ontap-antivirus-connector-task.html["Seite zur Installation des ONTAP Antivirus Connector"] Anweisungen verwendet werden.

[NOTE]
====
Für die Notfallwiederherstellung und MetroCluster Konfigurationen ist es erforderlich, separate Vscan Server für die primären/lokalen und sekundären/Partner ONTAP Cluster einzurichten und zu konfigurieren.

====


[[antivirus-software-requirements]]
== Anforderungen an Antivirensoftware

* Informationen zu den Anforderungen an Antivirensoftware sind in der Dokumentation des Herstellers enthalten.
* Informationen zu den von Vscan unterstützten Anbietern, Software und Versionen sind unter link:../antivirus/vscan-partner-solutions.html["Vscan Partnerlösungen"] verfügbar.




[[ontap-antivirus-connector-requirements]]
== Anforderungen an den ONTAP Antivirus Connector

Jede SVM verwendet entweder ICAP oder Antivirus Connector, nicht beides.

* Sie können den ONTAP Antivirus Connector von der link:http://mysupport.netapp.com/NOW/cgi-bin/software["Software-Download"^] Seite auf der NetApp Support Site herunterladen.
* Informationen zu den vom ONTAP Antivirus Connector unterstützten Windows-Versionen und den Interoperabilitätsanforderungen finden sich unter link:../antivirus/vscan-partner-solutions.html["Vscan Partnerlösungen"].
+
[NOTE]
====
Sie können verschiedene Versionen von Windows Server für unterschiedliche Vscan Server in einem Cluster installieren.

====
* Auf dem Windows Server muss .NET 3.0 oder höher installiert sein.
* SMB 2.0 muss auf dem Windows Server aktiviert sein.




[[icap-capable-scan-engine-requirements]]
== Anforderungen an eine ICAP-fähige Scan-Engine

Jede SVM verwendet entweder ICAP oder Antivirus Connector, nicht beides.

* Ab ONTAP 9.20.1 unterstützt ONTAP einen ICAP-basierten Scanpfad, der den Antivirus Connector überflüssig macht.
* ICAP unterstützt Linux-basierte Scan-Engines und benötigt weder Windows, .NET noch SMB 2.0.



NOTE: Wenn Sie von ONTAP 9.20.1 auf eine frühere Version zurückkehren, müssen Sie zuerst alle ICAP-Konfigurationen entfernen.

Weitere Informationen zu link:icap-vscan.html["ICAP-basierte Vscan Konfigurationen"].
