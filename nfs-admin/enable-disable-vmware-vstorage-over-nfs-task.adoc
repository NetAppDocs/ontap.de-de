= VMware vStorage über ONTAP NFS aktivieren oder deaktivieren
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Sie können die Unterstützung für VMware vStorage über NFS auf Storage Virtual Machines (SVMs) mithilfe des `vserver nfs modify` Befehls aktivieren oder deaktivieren. Diese Einstellung steuert VMware VAAI über NFS Vorgänge wie Copy Offload und Speicherplatzreservierung.

.Über diese Aufgabe
Standardmäßig ist die Unterstützung für VMware vStorage über NFS deaktiviert.

Ab ONTAP 9.20.1 unterstützt die Aktivierung von VMware vStorage over ONTAP NFS auch die automatische Speicherplatzrückgewinnung für per Thin Provisioning bereitgestellte NFSv3- und NFSv4.1-Datastores.

.Schritte
. Überprüfung der aktuellen VMware vStorage over NFS-Einstellung für die SVM:
+
`vserver nfs show -vserver vserver_name -fields vstorage`

. Führen Sie eine der folgenden Aktionen aus:
+
[cols="2*"]
|===
| Wenn Sie möchten... | Führen Sie den folgenden Befehl aus... 


 a| 
VMware vStorage-Unterstützung aktivieren
 a| 
`vserver nfs modify -vserver vserver_name -vstorage enabled`



 a| 
VMware vStorage-Support deaktivieren
 a| 
`vserver nfs modify -vserver vserver_name -vstorage disabled`

|===
. Überprüfung, ob die Einstellung aktualisiert ist:
+
`vserver nfs show -vserver vserver_name -fields vstorage`



.Nachdem Sie fertig sind
Sie müssen das NetApp NFS Plug-in für VMware VAAI installieren, bevor Sie diese Funktionalität verwenden können. Die automatische Speicherplatzfreigabe erfordert Version 3.0 oder höher.

Informationen zu VMware Host-, Plug-in- und Interoperabilitätsanforderungen sind in der NetApp NFS Plug-in for VMware VAAI Dokumentation und im NetApp Interoperability Matrix Tool zu finden.
