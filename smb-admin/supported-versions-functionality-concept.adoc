= Unterstützte ONTAP SMB Versionen und Funktionen
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Server Message Block (SMB) ist ein Remote-Dateifreigabeprotokoll, das von Microsoft Windows Clients und Servern verwendet wird. ONTAP unterstützt alle SMB-Versionen. Sie sollten überprüfen, ob der ONTAP SMB-Server die in Ihrer Umgebung erforderlichen Clients und Funktionen unterstützt.

Die aktuellsten Informationen darüber, welche SMB-Clients und Domänencontroller ONTAP unterstützt, sind im _Interoperability Matrix Tool_ verfügbar.

SMB 2.0 und spätere Versionen sind für ONTAP SMB Server standardmäßig aktiviert und können je nach Bedarf aktiviert oder deaktiviert werden. Ebenso kann SMB 1.0 je nach Bedarf aktiviert oder deaktiviert werden.

Ab ONTAP 9.20.1 unterstützt ONTAP SMB-Namensabfragen mit normalisierten Namen für geöffnete Dateien und Verzeichnisse. Windows-Clients können kanonische Datei- und Verzeichnisnamen in einer einzigen Anforderung abrufen.

[NOTE]
====
Die Standardeinstellungen für SMB 1.0- und 2.0-Verbindungen zu Domänencontrollern hängen ebenfalls von der ONTAP Version ab. Weitere Informationen zum  `vserver cifs security modify` Befehl finden Sie in der link:https://docs.netapp.com/us-en/ontap-cli/vserver-cifs-security-modify.html["ONTAP-Befehlsreferenz"^]. Für Umgebungen mit vorhandenen CIFS-Servern, auf denen SMB 1.0 ausgeführt wird, empfiehlt NetApp so bald wie möglich die Migration auf eine neuere SMB-Version, um sich auf Verbesserungen bei Sicherheit und Compliance vorzubereiten. Einzelheiten erhalten Sie bei Ihrem NetApp Ansprechpartner.

====
